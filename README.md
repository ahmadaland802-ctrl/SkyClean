# SkyClean Website

A static website for the SkyClean HITEX 2026 exhibition project.

## Edit these first
- Team member names and roles in `index.html`
- Social/contact links in `index.html`
- Replace the concept illustration later with your real project photos
- Update the project description after the prototype is tested

## Publish
Upload the files to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
